User CountStatusBottleneck
100 users
✓ Fine 		No issues. Supabase free tier + Vercel handles this easily.
1,000 users
✓ Fine (was Degrading) 		DB indexes eliminate the full table scan latency that previously caused visible slowdowns at this tier. Pagination prevents large fetches.
10,000 users
✓ Mostly Fine (was Painful) 		Indexes + pagination handle this comfortably. The 100-row limit prevents OOM. Supabase free tier connection pool (25 connections) may become a bottleneck under burst traffic — upgrade to Supabase Pro ($25/mo) adds 100 connections.
50,000 users
⚠ Manageable with config 		Requires Supabase Pro (connection pooling) + Vercel Pro (function concurrency). Rate limiting on /api/chat needed to prevent single user from exhausting Gemini quota. Inngest needed so webhook failures don't leave users on wrong plan at scale.
