Important Technical Notes

Self-Healing DB Pattern: All schema changes use ALTER TABLE "table" ADD COLUMN IF NOT EXISTS ... inside ensureTablesExist(). This function runs once per server process (singleton promise pattern). New columns are safe to add — they run on first request after deploy. Never use drizzle-kit push/migrate commands on this project.
SM-2 Algorithm (Flashcards): easeFactor starts at 2.5. Again: ef -= 0.2, interval = 1. Hard: ef -= 0.15, interval × 1.2. Good: ef unchanged, interval × ef. Easy: ef += 0.15, interval × ef × 1.3. dueDate = today + interval days. New cards start with dueDate = now() so they're immediately reviewable.
PayMongo Webhook Verification: Header format: t=<unix_timestamp>,te=<hex_hash>. Signature: HMAC-SHA256(webhook_secret, "<t>.<rawBody>"). Must read request as raw text (not JSON) before verification. Implemented in app/api/webhooks/paymongo/route.ts.
Stripe Webhook: Raw body must be read as Buffer.from(await req.arrayBuffer()). Do NOT parse JSON first or signature verification fails. Implemented in app/api/webhooks/stripe/route.ts.
jsPDF — Browser Only: jsPDF is installed but only works in the browser. Server actions return string content; the client component handles the download. Never import jsPDF in server actions or API routes.
Plan Inheritance for Teams: isPro() checks the user's own profiles.plan first. If 'free', it then checks team_members JOIN teams — if a team's subscriptionStatus is 'active', the member gets Pro-level access. Team subscriptionStatus is only set when the team owner pays for the Teams plan.
Stale .next Cache: If the app returns 500 with "React Client Manifest" errors after code changes, delete the .next folder and restart the dev server. This is a Turbopack known issue with certain file structure changes.
Onboarding Preferences Schema: profiles.preferences is a JSON column. After Phase 7, the shape is { preferredIDE, languages[], workflow, learningTrack, primaryGoal }. learningTrack values: web-dev | backend | cs-fundamentals | mobile | data. primaryGoal values: get-a-job | build-project | pass-bootcamp | learn-for-fun. These can power roadmap template auto-selection in a future update.
Clerk v5 Redirect API: afterSignInUrl / afterSignUpUrl props are deprecated in Clerk v5. Use fallbackRedirectUrl (redirects only if no other redirect is pending) or forceRedirectUrl (always redirects). Both <SignIn> and <SignUp> now use fallbackRedirectUrl="/dashboard". The env vars NEXT_PUBLIC_CLERK_SIGN_IN_FALLBACK_REDIRECT_URL are the v5 equivalents of the old NEXT_PUBLIC_CLERK_AFTER_SIGN_IN_URL.
